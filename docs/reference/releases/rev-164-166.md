# Revisions 164, 166 in 9/stable channel
Nov 18, 2026

A new version of Charmed Valkey has been published in the `9/stable` channel. The release contains additional
permissions for client relation users, security updates and a few bug fixes.

[Charmhub](https://charmhub.io/valkey) | [Deploy guide](how-to-deploy) |
[Upgrade instructions](how-to-refresh) | [System requirements](requirements)

## Features

* Allow `TIME` and `SELECT` commands for client relation users [#214](https://github.com/canonical/valkey-operator/pull/214)
* Add safeguards for TLS transition [#191](https://github.com/canonical/valkey-operator/pull/191)
* Avoid unit with stale data to become primary on full cluster crash recovery [#218](https://github.com/canonical/valkey-operator/pull/218)

### Bug fixes

* Verify LDAPS server IP SANs with OpenSSL [#219](https://github.com/canonical/valkey-operator/pull/219)
* Retry LDAP enable after a failed bind secret read [#222](https://github.com/canonical/valkey-operator/pull/222)
* Send STARTTLS before the LDAP sync bind [#223](https://github.com/canonical/valkey-operator/pull/223)

### Security updates

* Bump `certifi` from 2026.7.22 to 2026.10.19 [#211](https://github.com/canonical/valkey-operator/pull/211)
* Bump `oauthlib` from 4.0.0 to 4.0.1 [#215](https://github.com/canonical/valkey-operator/pull/215)
* Bump `pyasn1` from 0.6.4 to 0.6.5 [#216](https://github.com/canonical/valkey-operator/pull/216)

### Other improvements

* Keep topology observer log across restarts [#212](https://github.com/canonical/valkey-operator/pull/212)
* Bump snap and rock artifacts [#210](https://github.com/canonical/valkey-operator/pull/210)
* Update CI workflows [#217](https://github.com/canonical/valkey-operator/pull/217)
* Add integration test for upgrade path from first stable release [#206](https://github.com/canonical/valkey-operator/pull/206)
* Add issue templates [#209](https://github.com/canonical/valkey-operator/pull/209)
* Remove warning about unstable version from docs [#207](https://github.com/canonical/valkey-operator/pull/207)
* Add release notes [#205](https://github.com/canonical/valkey-operator/pull/205)

### Software and charm interface requirements

* Juju v3.6.29+
  * Older minor versions of Juju 3 may be compatible, but are not officially supported.
* Relation interface `valkey_client`
  * support for `data-interfaces` v1
  * backward compatibility for `data-interfaces` v0
* Integration with a TLS provider charm
  * `tls-certificates` interface v4
  * `certificate_transfer` interface v1
